# Snowy Desktop

A small Windows app that adds falling snow over the desktop. Minimize the settings window to keep the snow running in the background; restore it from the taskbar whenever you need it.


## Settings

- Use the sliders to adjust the **number**, **speed**, and **size** of snowflakes, and the **wind**.
- **Accumulate snow** toggles snow buildup.
- **Snow depth at the bottom edge** sets the maximum snow depth.
- **Pause** stops the snowfall until resumed.
- **Minimize settings** hides the settings window in the taskbar while the snow keeps running.
- **Turn off snow** closes the app.

Snow appears over the screen, but the overlay should not block clicks on icons or windows. Snow builds up along the bottom edge; the app does not currently detect individual icon shapes.
